# 大肥鱼角色预设

给微信群里那条「会打字的鱼」用的一张 Agent 预设。

## 装了什么

一条 `@deepseek-ai/dsh-agent-preset` 预设声明：

| 字段 | 值 |
| --- | --- |
| preset id | `dafeiyu` |
| 显示名 | 大肥鱼 |
| 工具 | 联网搜索（`tool-web`）、出图（`present`）、文件读写（`tool-fs`）、时间上下文 |

工具是刻意收窄的：群聊机器人不需要 plan mode、subagent、office，每样工具都是每轮请求的固定开销。

## 怎么用

1. 装好后打开 **设置 → 通用 → Agent 预设**，默认预设切成「大肥鱼」。
2. 微信桥接那边**清掉当前会话绑定**（或直接说一句新会话），下一条消息就会按这张卡新建会话。
3. 想回原样：把默认预设切回 `standard`，这张卡留着不影响别的东西。

## 角色卡写了什么

`cordis.patch.yml` 里 `persona.prefix` 那一段就是角色卡，直接改那段文字就能调口吻：

- 一句一条、短、不刷屏
- 口语、不卖萌、不用 Markdown
- 不懂就说不会，涉及节气/看相标「老话说」，不装权威
- 只有被叫到才接话

改完要重启 DSH（预设定义在启动时加载，已有会话保持原组成，只影响之后新建的会话）。
